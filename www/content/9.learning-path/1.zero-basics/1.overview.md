---
title: 路线概览
description: 零基础用户的大模型学习路径与整体节奏。
---


这一条路线适合：

- 完全没有 AI / 大模型基础的用户
- 有编程基础但没接触过大模型的开发者
- 想快速入门并做出第一个 AI 应用的人

---

## 🎯 学习目标

完成这一阶段后，你应该具备：

- 理解大模型的基本工作原理（Transformer、Token）
- 能使用 API 调用模型（OpenAI / Claude / 国内模型）
- 能写出基础 Prompt
- 能做一个简单的 AI 对话应用

---

## 🧭 学习路径

分为 3 个阶段：

### 第一阶段：基础认知
- 什么是大模型
- Token / Embedding
- Prompt 基础

### 第二阶段：动手实践
- 调用 API
- 构建简单对话
- 管理上下文

### 第三阶段：第一个项目
- 完成一个 AI Chat Demo
- 支持上下文记忆
- 简单 UI

---

## ⏱ 建议时间

- 每天 1~2 小时
- 约 7~14 天完成

---

## 🚀 下一步

👉 完成后进入：

- 开发者转大模型
- 或直接进入项目实战
