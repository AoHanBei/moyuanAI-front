**简单回答**

Agent 失败通常不是单点问题，而是模型决策、工具接口、上下文组织和执行环境共同导致的。

**详细解析**

- 常见问题包括：计划不合理、工具选择错误、参数填错、状态记忆混乱、上下文污染、循环调用和过度推理。
- 很多失败看起来像模型笨，实际上是系统没有给到清晰边界和稳定反馈。
- 工具链越多、任务越长、上下文越复杂，失败概率通常越高。
- 所以 Agent 工程很强调可观测性和中间过程日志。

**面试时可以这样答**

一个好回答要体现：你知道 Agent 失败多发生在链路交界处，而不只是模型输出本身。
