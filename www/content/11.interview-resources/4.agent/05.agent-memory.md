**简单回答**

Agent Memory 不是把所有对话都塞回上下文，而是按用途管理不同层级的信息。

**详细解析**

- 短期记忆通常是当前任务窗口内的上下文，用来保持本轮推理连贯。
- 长期记忆通常存储用户偏好、历史事实、项目背景等可复用信息，常通过向量检索或结构化存储实现。
- 记忆系统最难的不是存，而是“该写什么、什么时候写、什么时候读、怎么避免污染”。
- 如果没有筛选策略，记忆会迅速膨胀，最后把检索和生成都拖垮。

**面试时可以这样答**

面试时别只说短期和长期，要强调记忆写入策略和质量控制。
