---
title: 02. Self-Attention 的计算流程是什么？
description: 整理自注意力的输入、计算步骤与核心作用。
toc: false
---

**简单回答**

Self-Attention 的本质是：让每个 token 根据和其他 token 的相关性，动态聚合上下文信息，得到新的表示。

**详细解析**

- 输入 hidden states 后，先线性映射得到 Q、K、V 三组向量。
- 用 Q 和 K 做相似度计算，常见形式是 QK^T / sqrt(d_k)，得到每个 token 对其他 token 的注意力分数。
- 经过 mask 和 softmax 后，得到归一化权重，再对 V 做加权求和，形成新的上下文表示。
- 在大模型里，这个过程会在多个头上并行进行，每个头关注不同模式，最后再拼接映射回原维度。

**面试时可以这样答**

回答时最好把“算分数、做归一化、加权求和”这三步明确说出来，这比只背公式更像真的理解。

**常见追问**

- 为什么要除以 sqrt(d_k)？
- causal mask 在哪里起作用？
