---
title: 04. MHA、MQA、GQA 有什么区别？
description: 整理多头注意力和几种常见变体的差别。
toc: false
---

**简单回答**

三者的核心差别在于 Query 头数和 Key/Value 头数是否一一对应，这直接影响推理显存和速度。

**详细解析**

- MHA 是每个头都有独立的 Q、K、V，表达能力强，但 KV Cache 占用也最大。
- MQA 是多个 Query 头共享一组 K/V，显著降低 KV Cache 开销，推理更省显存，但表达能力可能有损失。
- GQA 介于两者之间，多组 Query 共享分组后的 K/V，是当前很多大模型比较常见的折中方案。
- 从工程角度看，这类改动往往不是为了训练效果，而是为了解决长上下文和高并发推理的成本问题。

**面试时可以这样答**

回答时不要只停留在定义，最好补一句“它们本质是在效果和推理成本之间做 trade-off”。
